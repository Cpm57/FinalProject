# This is the Habit Tracker App

## Overview
The Habit Tracker App helps users track their daily, weekly, and monthly habits. It allows users to:
- Add new habits.
- Mark habits as complete or incomplete.
- Filter habits by frequency (daily, weekly, or monthly).
- Switch between light and dark modes for a personalized experience.

## Features
- **Add Habit**: Users can add new habits and select their frequency (daily, weekly, monthly).
- **Toggle Completion**: Mark habits as completed or incomplete by clicking on them.
- **Filter by Frequency**: Easily switch between daily, weekly, or monthly habits using tabs.
- **Dark Mode**: Toggle between light and dark themes for a better viewing experience.
- **Remove Habit**: Delete habits that are no longer needed.

## Tech Stack
- **React**: The frontend framework for building the user interface.
- **CSS**: Used for styling the app, including the light and dark themes.
